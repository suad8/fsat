# نظام التصميم — «المطبعة الحيّة»

اتجاه جريء: أسطح داكنة بحبر ملوّن يطفو، عناوين ضخمة بكلمات مقنّعة، ذهب فويل،
وحركة GSAP تقودها مؤشرات الشاشة. الألوان الأساسية (بنفسجي/ذهبي) من ملف هوية
الشركة وتبقى قابلة للتغيير من `/admin/theme`.

## الرموز (`src/app/globals.css`)
- ثابتة (لا يغيّرها محرّر الثيم): `--color-ink` (حبر داكن)، `--color-magenta`.
- من الثيم: `primary-*`, `accent-*`, `brand-*` (+ ألوان التباين المحسوبة).
- الانحناءات حتى 2rem، الظلال المصبوغة `shadow-card/-hover/-pop/-glow`.
- العناوين وزن 800–900 بتباعد سالب خفيف.

## أدوات الطباعة (utilities)
`halftone` · `halftone-fade` · `crop-marks` · `foil-text` · `grain` · `spotlight` · `shine` · `text-outline`
(لا تُستخدم أبدًا مع `letter-spacing` على النص العربي: يقطع اتصال الحروف.)

## الصفحة الرئيسية (بالترتيب)
1. **Hero** — قرص حبر طافٍ يتبع المؤشر، عنوان بكلمات تصعد من خلف قناع، شارة دائرية تدور.
2. **TickerBand** — شريط ذهبي مائل بنص ضخم.
3. **CategoriesRail** — الأقسام لوحات ملوّنة؛ على الشاشات الكبيرة تُثبَّت الصفحة ويتحرك الشريط أفقيًا (pin + scrub)، وعلى الجوال شريط سحب بـ snap.
4. **StatsBand** — أرقام ضخمة تعدّ عند الوصول.
5. أقسام تحرّرها الإدارة من `/admin/theme` (ترتيبًا وإخفاءً): المنتجات، الخدمات (`ServicesList` تحريرية)، الأعمال، لماذا نحن (bento)، خطوات الطلب (خط زمني)، الآراء، التواصل.

## الحركة (GSAP) — `src/lib/gsap.ts`
كل الحركات داخل `gsap.matchMedia()` فتتوقف عند `prefers-reduced-motion`، والحالة المخفية
الابتدائية في CSS لا تُطبَّق إلا مع `(prefers-reduced-motion: no-preference) and (scripting: enabled)`.

قاعدة مهمة: لا تستخدم `clearProps` على عنصر حالته الابتدائية المخفية معرّفة في CSS
(يعيد CSS إخفاءه بعد الحركة). الاستثناء `Reveal` الذي يضيف `.is-visible` قبل المسح.

| المكوّن | الوظيفة |
|---|---|
| `Reveal` / `Intro` | ظهور عند التمرير / مدخل ترويسات الصفحات |
| `HeroMotion` | كلمات العنوان، الأقراص، بارالاكس، دوران |
| `CategoriesRail` | تمرير أفقي مثبّت |
| `StatsBand` | عدّادات ScrollTrigger |
| `StepsTimeline` | خط زمني يمتلئ مع التمرير |
| `Tilt` · `Magnetic` · `CustomCursor` | تفاعل المؤشر الدقيق فقط |
| `Marquee` | شريط لا نهائي (`large` للنسخة الضخمة) |
| `ScrollProgress` · `Header` | شريط التقدّم · إخفاء الهيدر عند النزول (يحرّك `top` لا `transform`) |
