# خطة مشروع موقع شركة الطباعة والتجهيزات الدعائية

> **حالة الملف المرفق:** لم يصل ملف الهوية. تم بناء هذه الخطة بحيث تكون **مستقلة عن الهوية البصرية**،
> وكل ما يخص الألوان والخطوط والشعار مركّز في ملف واحد (`src/config/brand.ts`) يُستبدل عند وصول الملف
> دون لمس أي مكوّن آخر.

---

## 1. الهيكل التقني

| الطبقة | التقنية | السبب |
|---|---|---|
| الإطار | **Next.js 15 (App Router)** | SSR/SSG لتحسين محركات البحث، تقسيم الكود تلقائيًا، سرعة عالية |
| اللغة | **TypeScript** | أمان الأنواع في نظام خيارات المنتجات المعقّد |
| التنسيق | **Tailwind CSS v4** + متغيرات CSS | RTL أصلي عبر `dir="rtl"`، أحجام حزمة صغيرة |
| قاعدة البيانات | **Prisma ORM** — SQLite للتطوير، PostgreSQL للإنتاج | تبديل بسطر واحد، بدون إعادة كتابة |
| الصور | `next/image` + Sharp | تحسين تلقائي، WebP/AVIF، Lazy Loading |
| المصادقة | Auth.js (جلسات + بريد/كلمة مرور مشفّرة bcrypt) | حماية لوحة التحكم |
| الرفع | تخزين محلي مع تحقق MIME + حد حجم + إعادة تسمية | جاهز للتحويل إلى S3/R2 لاحقًا |
| الحركات | CSS transitions + `prefers-reduced-motion` | لا مكتبات ثقيلة، لا تأثير على السرعة |
| النشر | Vercel / VPS (Docker) | مرن |

**لماذا لوحة تحكم مخصّصة بدل CMS جاهز:** نظام خيارات المنتجات هنا غير قياسي (مقاس + خامة + وجه واحد/وجهين
+ تشطيب + شرائح كميات + معدّلات سعر لكل خيار). أنظمة CMS العامة تتعامل معه بشكل ملتوٍ. اللوحة المخصّصة
تعطي حقولًا مطابقة لطبيعة عمل مصنع الطباعة، وبواجهة عربية RTL كاملة.

## 4. تجربة المستخدم ومسار الطلب

ثلاثة مسارات متوازية — العميل يختار الأنسب له:

**المسار (أ) — شراء مباشر** *(منتجات ذات سعر ثابت أو شرائح كميات)*
```
المنتج → اختيار الخيارات → السعر يتحدّث لحظيًا → رفع التصميم (اختياري)
      → أضف للسلة → السلة → إتمام الطلب → الدفع → تأكيد + رقم طلب
```

**المسار (ب) — طلب عرض سعر** *(منتجات ذات مواصفات مفتوحة: لوحات، أكريليك، مشاريع خاصة)*
```
المنتج / الخدمة → "طلب عرض سعر" → النموذج معبّأ مسبقًا بالمنتج والخيارات المختارة
      → إرسال → رسالة تأكيد + رقم مرجعي → الإدارة ترسل العرض → الدفع
```

**المسار (ج) — واتساب مباشر** *(الأسرع، وغالبًا الأكثر استخدامًا في السوق السعودي)*
```
أي صفحة → زر عائم ثابت
صفحة منتج → زر واتساب برسالة جاهزة تحوي:
      اسم المنتج · المقاس · الكمية · الخيارات المختارة · رابط المنتج · ملاحظات العميل
```

**قرارات تجربة استخدام مهمة:**
- عرض السعر يُحدَّث فوريًا مع كل تغيير خيار، مع تفصيل واضح: سعر الوحدة × الكمية + الإضافات.
- المنتجات `QUOTE_ONLY` لا تعرض زر "أضف للسلة" إطلاقًا — لا أزرار معطّلة.
- رفع التصميم متاح في مرحلة المنتج وأيضًا بعد الطلب (كثير من العملاء يطلب أولًا ويرسل التصميم لاحقًا).
- شريط سفلي ثابت على الجوال في صفحة المنتج: السعر + "أضف للسلة" + واتساب.
- الحالات الفارغة مصمّمة: سلة فارغة، لا نتائج بحث، تصنيف بلا منتجات، معرض بلا مشاريع.

## 6. تحسين محركات البحث

- `generateMetadata` لكل صفحة ديناميكية (عنوان + وصف + Open Graph)
- بيانات منظّمة JSON-LD: `Organization`, `LocalBusiness`, `Product` (+`Offer`), `BreadcrumbList`, `FAQPage`
- `sitemap.xml` و `robots.txt` مولّدان تلقائيًا من قاعدة البيانات
- روابط عربية واضحة (slug) + نص بديل إلزامي لكل صورة في لوحة التحكم
- تحسين البحث المحلي: اسم الشركة + المدينة + الخدمة في العناوين والمحتوى بشكل طبيعي

## 7. الأمان

- تحقق من نوع الملف (MIME حقيقي وليس الامتداد فقط) + حد أقصى للحجم + إعادة تسمية عشوائية
- التحقق من كل المدخلات على الخادم عبر Zod (لا يُعتمد على تحقق المتصفح)
- حماية النماذج من الإرسال الآلي (Honeypot + Rate limiting)
- تنقية أي محتوى HTML قبل العرض
- كلمات مرور مشفّرة، جلسات آمنة، حماية مسارات `/admin` عبر Middleware

## 9. المعلومات الناقصة (مطلوبة منك)

### حرجة — تمنع اكتمال الهوية البصرية والمحتوى
1. **ملف الهوية**: الشعار (SVG أو AI أو PNG شفاف عالي الدقة) · أكواد الألوان HEX · أسماء الخطوط
2. **اسم الشركة الرسمي** بالعربية والإنجليزية + الشعار النصي (Tagline) إن وُجد
3. **بيانات التواصل**: رقم الجوال · رقم واتساب · الهاتف الثابت · البريد · العنوان · رابط الموقع على خرائط جوجل · ساعات العمل
4. **صور الأعمال السابقة** + تفاصيل كل مشروع (الاسم، النوع، الخامات، المقاسات)

### مهمة — تؤثر على المتجر والفواتير
5. **قائمة المنتجات الفعلية**: الأسماء · المقاسات · الخامات · الأسعار أو شرائح الكميات · أيّها بسعر مباشر وأيّها بعرض سعر
6. **الرقم الضريبي · رقم السجل التجاري** · هل الأسعار **شاملة** الضريبة أم لا
7. **مدن الشحن + التكاليف** + شركة الشحن المعتمدة + حد الشحن المجاني إن وُجد
8. **بوابة الدفع** المستهدفة (Moyasar / PayTabs / تابي / تمارا / مدى…)
9. **المدينة الرئيسية** للنشاط — ضرورية للبحث المحلي

### مكمّلة
10. صور المكائن والمعدات + أسماؤها وإمكانياتها
11. آراء عملاء حقيقية (اسم · جهة · نص) — أو الموافقة على تركها فارغة حتى تتوفر
12. حسابات التواصل الاجتماعي
13. نصوص السياسات الأربع — أو الموافقة على صياغتها كمسوّدة قابلة للمراجعة القانونية
14. الدومين والاستضافة المستهدفة

> كل نص أو صورة غير متوفرة سيُوضَع مكانها محتوى احترافي **معلّم بوضوح** بعلامة `[[يحتاج استبدال]]`
> في لوحة التحكم وفي الكود، ولن يبقى أي نص وهمي غير معلّم في النسخة النهائية.
