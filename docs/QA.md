# الجودة

## تشغيل الفحوص
| الأمر | يغطي |
|---|---|
| `npm run typecheck` / `npm run lint` | الأنواع وجودة الكود |
| `npm test` | اختبارات وحدة (vitest): التسعير، التحقق، حدّ المعدّل، الأدوات، الثيم/واتساب |
| `npm run test:data` | منطق الطلبات والبذر والتسعير على قاعدة SQLite مؤقتة |
| `npm run test:e2e` | دخان playwright على كل مسارات `sitemap.xml` (200، لا أخطاء console، لا تمرير أفقي، كل العناوين ظاهرة، لا `[[`، title/description/canonical، الروابط والصور) |
| `bash scripts/qa/railway-start-test.sh` | مسار تشغيل Railway: هجرات ← بذر أول مرة ← `/api/health` ← إعادة تشغيل بلا بذر |

`npm run build` يُجهّز قاعدة مؤقتة نظيفة (انظر `scripts/build.mjs`) ثم يبني.
CI: `.github/workflows/ci.yml` (typecheck, lint, test, build, e2e).

## ما تحقّق منه الدمج الأخير
- 185 اختبار وحدة و70 اختبار بيانات تمرّ، و52/52 مسارًا في فحص الدخان (وضع `--quick`).
- تسجيل دخول الإدارة وفتح 11 صفحة إدارة بلا أخطاء console ولا تمرير أفقي على الجوال.

## لم يُنجَز بعد (بصدق)
- فحص وصول آلي (axe/WCAG) — لم يُكتب؛ أُزيل من CI.
- قياس أداء رقمي قبل/بعد (LCP/حجم JS) وتحسين صور `public/brand/mascot.png` (≈ 0.5MB).
- اختبارات e2e لرحلة الشراء كاملة (سلة ← دفع ← نجاح) وللإدارة (تعديل منتج، تغيير حالة طلب).
- اختبار النشر الفعلي خلف TLS على Railway.
